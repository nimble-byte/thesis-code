# Master Thesis Study Evaluation

This repository contains all the data and code used for the evaluation of the master thesis available under https://github.com/nimble-byte/master-thesis.

Qualitative data was focused for the evaluation. Detailed information about the procedure and data consult the [README](./qualitative/README.md).

The quantitative data was used as supporting evidence. Details can be found in the [README](./quantitative/README.md).

The folders are organised as described below:

```sh
evaluation/
├── qualitative/
│   ├── README.md
│   ├── codebook.py              # primary tool for codebook manipulation
│   ├── code-mapping.log.md      # working notes of coding changes
│   ├── codebooks/
│   ├── codes/                   # transcript codes
│   ├── formatted/               # formatted transcripts
│   ├── helpers/                 # helper scripts
│   ├── metadata/
│   ├── notes/
│   └── raw/                     # raw transcripts
└── quantitative/
    ├── README.md
    ├── evaluation.ipynb.        # main evaluation notebook
    ├── constants.py             # techincal constants
    ├── data/                    # input data for the quantitative evaluation
    └── out/                     # charts, data output of the quantitative evaluation
```
